## Proyecto Visitas

Esta carpeta concentra el proyecto de visitas al CMAT para que pueda convivir mejor con otros proyectos dentro del mismo repositorio.

Estructura principal:

- `notebooks/`: exploración y cuadernos del análisis.
- `scripts/`: utilidades y pipelines del proyecto.
- `info/`: tablas, figuras y fragmentos `.tex` generados para el reporte.
- `reporte/`: documento LaTeX y sus salidas.
- `visualizations/`: figuras exportadas del proyecto.
- `referencias/`: notas y material de apoyo.

Nota:

- Los datos crudos compartidos siguen viviendo en `../data/`.
